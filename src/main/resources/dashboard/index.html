04 / EXPERIMENT NOTES

Break things. Watch them recover.

  1. See a cache hit

    Send Catalog twice. The second response comes from the same user’s cache, with zero upstream attempts. It expires after 5 seconds.

  2. Exhaust your budget

    Burst × 20. Requests beyond the token budget get 429 + Retry-After, including cache hits. The budget refills over time.

  3. Open a circuit

    Select the failing Orders request and send it three times. Both replicas open after three consecutive failures. Health checks cannot close them.

  4. Recover with a probe

    After the 8-second cooldown, send a normal Orders request. One half-open trial can close each circuit on success.

  5. Kill a real service

    From the project folder: .\demo\run.ps1 -Action stop -Port 9202. Change stop to start to recover it.

No simulated packets, counters or circuit states. All values come from the running JVM.
